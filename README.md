# Wave Manifold App

Interactive environment for the construction and visualization of wave manifolds arising from 2×2 systems of conservation laws.

## Documentation

The complete technical documentation is maintained in `docs/book/`.

- Volume I — Mathematical Foundations
- Volume II — Numerical Algorithms
